# Specification

## Summary
**Goal:** Add four new Note categories across the Notes page filters and the Add/Edit Note category dropdowns.

**Planned changes:**
- Add four new category filter tabs on the Notes page: LDC, Food Service, Personal, Family, styled and behaving identically to existing category tabs.
- Update the Add Note modal Category dropdown to include the four new category options (without changing existing options).
- Update the Edit Note modal Category dropdown to include the four new category options, and ensure notes with these categories display/preselect and save without errors.

**User-visible outcome:** Users can filter notes by LDC, Food Service, Personal, or Family, and can create/edit notes using these categories from the Category dropdown.
